計算機網路｜Ch1–Ch2 自學網站
=================================

開啟方式（Windows / macOS / Linux）
1. 將整個 ZIP 解壓縮。
2. 雙擊 index.html，使用 Chrome、Edge 或其他現代瀏覽器開啟。
3. 不需安裝程式，不需連網，也不需架設伺服器。

網站包含
- 23 個學習單元：第一章核心觀念與計算題、第二章應用層與計算題。
- 保留上傳筆記的相關章節，點開「原始筆記」即可對照。
- 額外白話解釋及容易搞錯的地方，和原筆記分區呈現。
- 不含縮寫全名表、拼字背誦與縮寫填空測驗。
- 原理與計算選擇題（實際題數以網站首頁顯示為準）。
- 7 種公式工具：鏈路延遲、排隊延遲、吞吐量、HTTP 回應時間、快取使用率、P2P 分發下界、語音封包化。
- 學習進度、單元自評、個人筆記、錯題整理、深淺色切換。

使用小提醒
- 學習進度及筆記保存在「開啟此網站的瀏覽器」本機儲存空間，不會上傳到外部網站。瀏覽器清除網站資料、私密模式結束或更換裝置後可能消失。
- 公式工具寫出適用的假設，請依老師題目條件判斷，不能把簡化公式直接套用所有真實網路。
- 如瀏覽器的 file:// 本機頁面儲存政策不同，閱讀功能仍可用，學習進度可能無法保存。
- 網站不引用外部圖片、字型或 JS 套件，解壓縮後完全離線可用。
